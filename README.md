# LCDrone feedback and bug reports

This is where you can report bugs and share ideas for [LCDrone](https://thunderstore.io/c/lethal-company/p/347956/LCDrone/), a Duskers-inspired drone for Lethal Company that you control from the ship terminal.

This repository holds no code. It is only for feedback.

## Report a bug

[Open a bug report](../../issues/new?template=bug_report.yml). A good report has:

- **The LCDrone version.** It is in r2modman, or in your log as `Loading [LCDrone x.y.z]`.
- **The moon, and whether you were the host or a client.**
- **What you did, what you expected, and what happened.**
- **Your log file:** `BepInEx/LogOutput.log` in your profile folder. In r2modman, go to Settings > Browse profile folder. Drag the file into the report. Please send the log from the session where the bug happened, because the game overwrites it on every launch.

Before you open a report, check whether someone has already reported the same thing. If they have, add what you saw to their report.
